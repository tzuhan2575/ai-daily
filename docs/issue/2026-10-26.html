Anthropic 把 Agent Skills 標準捐給 Agentic AI Foundation

Anthropic・10/22

Anthropic 宣布將 Agent Skills（讓 AI 代理人取得專門知識與工作流程的開放標準）捐給 Linux Foundation 旗下的 Agentic AI Foundation（AAIF）。官方說自 2025 年 12 月公布標準以來，已有超過 70 個代理人平台整合，包括 ChatGPT、Cursor、GitHub Copilot、VS Code；累計發布 100 萬個 skills、近 2.8 億次安裝。

白話：一個 skill 就是一個資料夾，裡面有一份 SKILL.md，教代理人做某類事，還可以附腳本和參考資料。以前這套規格由 Anthropic 管，現在改交給中立組織，其他公司也能參與決定規格怎麼改。
💡 為什麼重要你如果在做開發工具或自動化流程，寫一次 skill 就能跨多個編輯器和代理人使用，不必綁定單一廠商。標準中立化也降低日後規格被單一公司左右的風險。
🎯 對你的影響　🔧 可立即用
你用 Claude Code，Agent Skills 就是它的擴充格式；既然現在成為跨工具的開放標準，你寫的 skill 以後可能在別的工具也能用。
▶ 把你最近重複貼給 AI 的一段流程，做成自己的 skill（見今日一課）。
📖 展開完整解析（6 段）

捐了什麼

Agent Skills 的名稱與標誌、GitHub 組織、agentskills.io 網域都移交給 AAIF。官方說不加入 AAIF 也可以繼續使用或貢獻這個標準。

AAIF 是什麼

AAIF 隸屬 Linux Foundation，官方說是去年由 Anthropic 與 Block、OpenAI 共同發起，Anthropic 也已把 Model Context Protocol（MCP）捐給它。這次是第二個捐出的標準。

skill 的來由

官方說他們在做 Claude Code 時發現模型處理一般知識工作沒問題，但缺少真實商業任務需要的流程知識，於是做出 skills。2025 年 10 月推出後數週內，開發者就在 GitHub 發布數千個 skills，並替 Codex、Cursor、OpenCode 寫了載入器，之後 Anthropic 才把它公開成開放標準。

維護方式

Anthropic、Google、OpenAI 等公司的工程師將以個人身分維護標準，Lead Maintainers 是 David Soria Parra 與 Mahesh Murag。

接下來的路線

官方提議先做三件事：有版本號的發行、正式的提案流程、給 skill 作者和安裝者的安全指引。最後一項值得留意，因為 skills 可以夾帶腳本，安裝別人的 skill 等於執行別人的程式。

怎麼看這些數字

70 個平台、100 萬個 skills、2.8 億次安裝都是 Anthropic 自己公布，我沒有找到第三方統計，也沒有讀到各平台的整合深度，只能當作官方說法。

Anthropic 讓 METR 以「類員工」身分進公司評估風險

Anthropic・10/15

Anthropic 宣布已開始給非營利評測機構 METR 的一支團隊「類員工存取權」：六位 METR 員工使用公司設備、辦公空間，並可接觸大致與內部風險評估團隊相當的內部工具與系統。METR 會公開發表風險評估結果。Anthropic 另外也與 SecureBio、Accenture 合作，並與包含 Hugging Face 在內的數個組織初步洽談。

白話：以前外部評測多半只能拿到模型來測。這次是讓外人像同事一樣坐進公司，看模型怎麼訓練、防護機制怎麼運作，再把結論公開。官方拿銀行監理比喻：監理單位派駐檢查員在大型銀行內部。
💡 為什麼重要AI 公司自己說「我們很安全」可信度有限，由有權限的第三方公開結論，是目前比較有說服力的做法。如果你在乎模型風險報告可不可信，這是值得追蹤的機制。
🎯 對你的影響　💤 略知即可
（推測）屬於 AI 安全評測的產業動態，與你的日常開發無直接關係。
📖 展開完整解析（6 段）

背景

官方說上個月已承諾加強獨立第三方評估，並簽署了白宮的 Accord on Super Intelligence，其中公司承諾與獨立外部稽核或評測者合作。METR 過去一年也已多次審閱 Anthropic 的風險報告。

他們認為評測者需要什麼

官方列出四項：能力評估的專業（包含知道評測可能被誤導，例如對齊偽裝）、獨立性（不持有被評公司股權，也不在財務或營運上依賴它）、足夠的存取權（不只最新模型，還包含訓練方式與防護如何運作）、自由發表觀察與結論的權利。

存取範圍

除了少數明確類別（客戶資料、律師與客戶保密特權資訊、模型架構資訊）之外，Anthropic 員工被鼓勵像對待一起做對齊風險的同事一樣分享資訊。這團隊在有法律效力的協議下運作，METR 其他員工與這個團隊的工作隔離。

發表權的限制

Anthropic 不能否決發表，但可以要求涵蓋在預先定義類別內的資訊（例如重現機密智財）被刪除；這些類別的最終認定權在 Anthropic，METR 保留對其取得的存取程度與資訊發表說明的權利。這是這套安排最值得細看的地方：獨立性很大程度取決於這個認定權怎麼用。

其他夥伴

SecureBio、Accenture 的合作還在早期，給的資訊較有限，發表權也較有限。我只讀了這篇公告，沒有讀到合作合約細節，也還沒有 METR 發表的結果可以看。

觀察點

METR 第一份基於這種存取權的公開報告是什麼時候、有沒有被要求刪減，以及其他公司是否跟進。

Anthropic 成立公益基金，承諾提撥 5% 股份

Anthropic・10/18

Anthropic 宣布成立 Anthropic Public Benefit Fund，是公司百分之百持有的新實體。在股東同意的前提下，先提撥 5% 的 Anthropic 股份；之後公司估值每高出某個基準線 50%，董事會可再酌情加撥 2%。官方稱加上共同創辦人與員工既有承諾後，約 20% 的股份會用於公共利益。

白話：公司把一部分自己的股份放進一個專門做公益的實體，而且公司越值錢，能放進去的比例越高。它是 LLC 而不是一般的 501(c)(3) 非營利組織，所以給錢的方式比較有彈性，例如大額捐給非營利組織，或直接發給特定族群。
💡 為什麼重要這是 AI 公司如何回應「AI 賺的錢誰受益」的一個具體做法。官方特別舉勞動市場衝擊為例，提到已承諾投入 2 億美元研究並處理這個問題，但認為進展這麼快可能需要更大膽的方法。
🎯 對你的影響　💤 略知即可
（推測）公司治理與公益承諾，不影響你的使用。
📖 展開完整解析（6 段）

結構

提撥 5% 需股東同意。另外每當估值比基準線再增加 50%，董事會可酌情加 2%。基準線與估值里程碑的數字公告裡沒有給，官方說未來幾個月會公布基金的結構、治理與里程碑。

為什麼用 LLC

官方說選 LLC 而非 501(c)(3) 是為了在不同形式的捐贈之間保有調整空間；這個實體持有的 Anthropic 股權不會用於遊說或政治捐款，不論在美國或海外。

與公司內部公益的分工

官方說公司內部已在做的事（AI 安全與可解釋性研究、應用生物醫學研究、對非營利與科研機構的 Claude 折扣）兼具公益與營利價值，所以放在公司內；基金則負責更大規模、更有彈性的做法。

和既有承諾的關係

官方說共同創辦人當初承諾捐出 80% 的持股，另有員工股權捐贈配對計畫，約一半員工參與。這些加上今天的宣布，合計約 20% 的股份。

官方的對比說法

官方說科技公司常提供隨公司成長而增加的高階主管報酬，他們選擇把這部分股權導向公益。這是公司自己的說法，我沒有讀到外部的分析或批評。

還沒有的資訊

基金治理由誰決定、錢怎麼分配、里程碑具體數字都未公布；官方預告會有一份公益報告。在這些出來之前，很難判斷實際影響。

Claude 的美國期中選舉防護：用量數據與新功能

Anthropic・10/14

Anthropic 分析 2026 年 9 月 21 至 27 日約 25 萬則美國 Claude.ai 消費者對話：約 5.75% 涉及政治、公共政策或社會議題，約 0.51% 專門談選舉或投票，要求 Claude 推薦投給誰的約 0.01%，違反選舉誠信政策的約 0.002%。官方並說 Opus 5.5、Sonnet 5.5、Haiku 5.5 在其政治中立性評測得 99%。

白話：他們用隱私保護的方式分類了一週的對話，看大家實際怎麼用 Claude 談政治。結果大多是查資訊、研究、寫文件，很少直接問要投給誰。另外 Claude 之後會在對話裡直接給出各州的投票資訊。
💡 為什麼重要這是少見的公司自己公開的「使用者實際怎麼談政治」數據，也示範了怎麼測政治偏見。如果你做面向大眾的 AI 產品，這些做法可以參考。
🎯 對你的影響　💤 略知即可
（推測）針對美國選舉的防護；若你之後做會碰到政治或選舉內容的聊天產品，可回頭參考他們的評測做法。
📖 展開完整解析（6 段）

數據方法

樣本是隨機抽取、約 25 萬則美國 Claude.ai 消費者對話，期間 9 月 21 到 27 日，由 Claude 以保護隱私的方式分類。因為推薦投票對象的請求太少，圖表顯示的是 95% 信賴區間的上限。這些都是官方數字，沒有第三方重現。

使用者實際在問什麼

官方說多數是資訊性請求：理解國際事件、研究候選人、草擬文件、課業、權衡政策正反論點。越接近選舉日預期比例會上升。

新功能：投票資訊

原本問到選民登記、投票所、選舉日期時會顯示連到 Democracy Works 旗下 TurboVote 的橫幅。官方說本月稍後 Claude 會把 Democracy Works 蒐集的官方資訊直接放進回答，讓美國使用者問在哪投票、帶什麼證件時得到該州的答案。

新功能：選舉結果

選舉夜及之後幾天，被問到最新開票或結果時，Claude 會顯示最新的官方數字。

政治偏見評測

官方說每次模型發布前都測政治偏見，Opus 5.5、Sonnet 5.5、Haiku 5.5 在政治中立性評測是目前最高、為 99%；並說新模型更願意參與政治討論、拒絕的請求更少。評測細節我沒有讀，分數是官方自評。

我沒讀到的部分

公告後半談到更多防止濫用與持續改進的內容，我只讀到前半，所以不在這裡下結論。

Anthropic 新加坡設辦公室，並與政府簽 MOU

Anthropic・10/14

Anthropic 在新加坡開設亞太第五個辦公室，並與新加坡數位發展及新聞部簽署合作備忘錄（MOU），在新加坡國際網路安全週場邊簽署。內容涵蓋 AI 安全、資安與模型評測合作、AI 採用與影響研究、公私部門負責任採用。官方說新加坡在其 Economic Index 的 121 個國家中，按人口比例的 Claude.ai 使用量排第 2，約是依人口規模預期的近 6 倍。

Agent Skills：把常貼的流程變成你自己的 skill

為什麼今天學這個

Anthropic 把 Agent Skills 標準捐給了 Agentic AI Foundation。這個格式你每天都在用，現在是學會自己寫的好時機。

skill 是什麼

一個 skill 就是一個資料夾，裡面至少有一個 SKILL.md。檔案開頭是 YAML 前置資料（frontmatter），之後是 Markdown 寫的操作說明。Claude Code 官方文件的說法是：建立 SKILL.md，Claude 就會把它加進工具箱，相關時自動使用，你也可以用 /skill-name 直接呼叫。

什麼時候該做成 skill

官方文件建議：當你一直把同樣的指令、檢查清單或多步驟流程貼進對話，或 CLAUDE.md 裡某一段已經長成「程序」而不是「事實」時，就適合做成 skill。skill 的內文只在用到時才載入，所以長篇參考資料平常幾乎不佔上下文。

格式規範

依開放標準規格：前置資料必填 name 與 description。name 最多 64 字，只能用小寫英數與連字號，不能以連字號開頭或結尾、不能有連續連字號，且必須與資料夾名稱一致。description 最多 1024 字，要寫清楚「做什麼」與「什麼時候用」，並包含關鍵字，讓 AI 判斷何時啟用。其餘如 license、compatibility、metadata、allowed-tools 是選填。

漸進載入

規格說明 AI 會分階段載入：一開始只讀名稱與簡短描述（約 100 token），決定要用時才讀完整的 SKILL.md，需要時才去讀 scripts/、references/、assets/ 裡的檔案。所以長內容建議拆成獨立檔案，保持 SKILL.md 精簡。

放哪裡

專案內放在 .claude/skills/<名稱>/SKILL.md；個人的放在你家目錄的 ~/.claude/skills/，你的電腦上已經有這個資料夾（我確認過）。官方文件也說舊的 .claude/commands/ 檔案仍然有效，與 skill 運作方式相同。

動手做（勾選記錄進度）

範例檔案

---
name: tw-summary
description: 把貼上的英文技術文章整理成繁體中文摘要，含三句重點、名詞白話解釋與對工程師的影響。當使用者貼上英文文章或要求「整理成中文」時使用。
---

# 繁中摘要

1. 先用三句話說明文章重點。
2. 列出專有名詞並用白話解釋。
3. 最後寫「這篇對 AI 軟體工程師的影響」，沒有影響就直說。
4. 只寫文章裡有的內容，不補充沒讀到的資訊。

貼給 Claude Code 的指令

請幫我在 ~/.claude/skills/tw-summary/ 建立一個 Agent Skill。SKILL.md 的 frontmatter 要有 name: tw-summary（小寫英數與連字號、與資料夾同名）與 description（說明：把貼上的英文技術文章整理成繁體中文摘要，何時使用）。內文寫步驟：1) 3 句重點 2) 專有名詞白話解釋 3) 這篇對 AI 軟體工程師的影響。完成後教我怎麼呼叫，並用一小段示範文字測試。
