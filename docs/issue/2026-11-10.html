Meta 推出最小模型 Muse Ember：官方說智慧指數追平 Claude Haiku 5.5，成本約三分之一

Meta 官方研究部落格（已讀）・11/9；HN 討論（只看標題與分數）

Meta 11/9 公布 Muse Ember，定位『最小、最有效率』，用於工具呼叫、程式子任務、路由、擷取與長文件解析。官方頁面沒給參數量，只寫 1M token 上下文、最多 512K 輸出。價格（提示 200K 內）每百萬 token 輸入 0.10 美元、快取輸入 0.004 美元、輸出 0.50 美元；模型代號 muse-ember-1.0，在 Meta Model API 與 Muse Code 提供，另提到 Google Cloud 與 Oracle Cloud。官方比較表（對手為 Claude Haiku 5.5 與 GPT-6 Luna，皆最高推理）：Artificial Analysis 智慧指數 36／36／28；AutomationBench-AA 37.8%／13.9%／20.2%；Terminal-Bench 4.0 40.9%／39.2%／16.4%；FrontierCode 2.0-AA 27.2%／34.9%／25.2%（Ember 落後 Haiku）。以上皆為 Meta 自己公布的數字，我沒讀到完整評測報告。

白話：白話：Meta 做了一個便宜又快、專門幫 agent 打雜的小模型，官方說在多數 agent 與寫程式測驗上跟競品小模型打平或更好，但不是每一項都贏。

我讀到什麼

讀了 It's FOSS 全文；沒讀 Asahi 原報告，所以事件細節皆為報導轉述。

為什麼從 MIT 換 GPL

MIT 只要求保留版權聲明，沒有要求開源衍生品。GPL 要求散布修改版時也要用同授權釋出原始碼，商業封閉分支失去誘因。作者也承認 GPL 擋不住鐵了心的人，移除署名本來就違反 MIT 的唯一條件。

歷史對照

報導提到 WINE 在 2002 年因公司做專有分支而由 MIT 改為 LGPL，Asahi 自比類似處境。

爭議

批評集中在 BSD 陣營：OpenBSD 的 Apple Silicon 支援仰賴 Asahi 的 m1n1 開機程式。報導說 Asahi 未解釋既有貢獻如何重新授權，也沒說所有貢獻者是否同意。

相關分支

報導提到 Aurora Silicon（Vulkan 驅動，Asahi 驅動的 fork）與 Gravity Linux（因 LLM 政策歧見分出），這是報導作者補充的脈絡，Asahi 報告並未點名。

觀察點

後續是否有其他逆向工程或硬體支援專案跟進；BSD 社群會不會續用。

📘 今日一課 · 10 分鐘

用 llama-server 在本機開一個 OpenAI 相容的小模型服務

為什麼今天學這個

今天 Meta 發布小模型 Ember（不開放本地執行）與成本討論，銜接第 4 週「本地跑小模型」的第三個主題：本地推論工具。內容出自 llama.cpp 官方 tools/server/README.md（已讀前約 100,000 字元，後段沒讀）；這個環境沒有安裝 llama-server，我沒有實際執行任何指令。

是什麼

llama-server 是 llama.cpp 專案附的 HTTP 伺服器，載入一個 GGUF 模型後，提供與 OpenAI 相容的 API。官方 README 列出 POST /v1/chat/completions 為 OpenAI 相容的 Chat Completions API。

為什麼值得學

因為相容 OpenAI 格式，很多現成工具只要改網址就能指向本機模型；本地跑的 token 不按量計價，只花電費與時間。代價是品質取決於你選的小模型與量化，我沒有數據替你比較。

怎麼啟動

官方範例：./llama-server -m models/7B/ggml-model.gguf -c 2048。-m 是模型路徑，-c 是上下文大小。README 也列出 -hf 語法 <user>/<model>[:quant]，範例值為 ggml-org/GLM-4.7-Flash-GGUF:Q4_K_M，可以直接從 Hugging Face 取模型（我只看到語法，沒看到完整指令說明）。

預設位址

我讀到的 README 摘要說預設監聽 127.0.0.1，埠號寫 9931；我對這個數字不完全有把握，請以伺服器啟動時印出的位址為準。--host 與 --port 可改。

怎麼呼叫

官方 curl 範例（簡化）：curl http://localhost:9931/v1/chat/completions -H "Content-Type: application/json" -H "Authorization: Bearer no-key" -d '{"model":"gpt-3.5-turbo","messages":[{"role":"user","content":"Write a limerick about python exceptions"}]}'。範例裡 model 欄位是佔位字串，本機伺服器只載入一個模型。

安全提醒

預設只綁定本機。若改成 0.0.0.0 對外開放，別人也能用你的機器，請先想清楚（這是我的一般性提醒，非 README 引述）。
