Anthropic 向美國 SEC 遞交 S-1，申請首次公開募股（IPO）

Anthropic・10/26

官方公告（10 月 26 日）說，Anthropic, PBC 已向美國證券交易委員會（SEC）提交 Form S-1 註冊聲明，擬公開發行 Class A 普通股。公告列出的資訊有限：預計在 Nasdaq Global Select Market 上市，代號「ANT」；承銷商為 Goldman Sachs 與 Morgan Stanley；發行股數與價格區間尚未決定；註冊聲明尚未生效，因此還不能出售或接受認購。

白話：白話：S-1 是公司要上市前交給主管機關的「公開說明書」。遞件不等於已經上市，要等 SEC 審查、聲明生效、定價之後才會開始交易。

Anthropic 設立公益基金：初始投入 5% 股份，並隨公司估值增加

Anthropic・10/18

官方文章（10 月 18 日）說，公司承諾把一部分股份投入新成立、全資持有的 Anthropic Public Benefit Fund。初始為公司股份的 5%（需股東同意）；董事會可在公司價值相對某個基準每增加 50% 時再加碼 2%（基準金額文中未說明）。基金採 LLC 形式而非 501(c)(3)，以便在不同捐贈形式間保持彈性；其持有的公司股權不會用於遊說或政治捐款。官方另稱共同創辦人在創立時承諾捐出 80% 股權，約一半員工參與股權捐贈配對，合計約 20% 股份投入公共利益（以上皆官方說法）。

白話：白話：公司承諾把一部分股份交給一個專門做公益的實體，而且公司越值錢，這個比例越高。重點是制度設計，不是現金捐款。

發生什麼

承諾以股份而非現金，初始 5%，並有隨估值提高的加碼機制：每 50% 增幅可加 2%，由董事會決定。基準金額沒有寫出。

結構選擇

官方說採 LLC，理由是要在捐給傳統非營利組織與直接發放給特定族群之間保持彈性。也明說股權不會用於遊說或政治捐款，國內外皆然。

與先前承諾的關係

文章提到公司先前已承諾 2 億美元用於研究與因應 AI 對勞動市場的影響，基金可能採取更大膽的做法（原文表述，具體做法未說明）。

其他說法

官方稱把原本會變成高額主管薪酬的股權導向公共利益；將在未來數月公布基金的結構、治理與估值門檻，並發布公益報告。

獨立評測更新：METR 六人小組獲「類員工」存取權

Anthropic・10/15

官方文章（10 月 15 日）說，Anthropic 已開始讓非營利評測機構 METR 的六人小組以「類員工」方式存取，使用公司配發的硬體、辦公空間與內部工具（與自家風險評估團隊大致相當）。官方稱簽署了一份白宮的 Accord，內容含與獨立外部稽核或評測方合作；也在與 SecureBio（審查 8 月風險報告中的化學與生物武器章節）、Accenture 合作，並與包含 Hugging Face 在內的其他組織初步接洽。

白話：白話：模型公司自己說自己安全不夠有說服力，所以請外部團隊進來看。這篇在講外部團隊能看到多少、能不能自由發表。

三層存取

官方分三級：第一級是範圍窄的調查，發表須經 Anthropic 同意；第二級可不經同意發表、可看較廣資訊，但公司仍可要求塗銷；第三級即 METR 的安排，有類員工存取，加上第二級的發表權。

發表自由

官方稱公司不能否決 METR 的發表，但可針對預先定義的類別（例如機密智財）要求塗銷；METR 的這個小組與其他員工隔離。

評測方條件

官方列出：專業能力、獨立性（無股權、財務或營運依賴）、足夠存取、可自由發表。

其他合作

SecureBio 審查 8 月風險報告的化學與生物武器章節，先前已做過前一份報告的試點審查；與 Accenture 與 Faculty 的規劃合作涵蓋模型評測與紅隊、對齊評估、防護測試與能力建設。文末註記 METR 與 SecureBio 的專案條款於 10/16、10/15 澄清。

Tool use：模型怎麼「動手」做事

為什麼今天學這個

課程第 2 週「Agent 與工具使用」，MCP 與 Skills 已上過，今天補最底層的 tool use。今天新聞提到代理人操作實驗儀器的規格，正好是「模型動手」的例子。以下為一般原理，非來自今日原文，我也沒有實際執行。

是什麼

模型本身只輸出文字。tool use 是：你先告訴模型有哪些工具（名稱、用途、參數格式），模型在需要時輸出一段結構化呼叫（例如要查天氣、參數是城市），由你的程式真的執行，再把結果當作新訊息交回模型，模型再據此回答。

為什麼重要

模型不會憑空知道今天的資料，也不能直接改檔案。有了 tool use，它才能查資料、讀寫檔案、操作系統。MCP 就是把『工具怎麼描述與連線』標準化。

怎麼運作（迴圈）

1) 送出問題與工具清單；2) 模型回傳『我要呼叫工具 X，參數 Y』；3) 你的程式執行 X；4) 把結果送回；5) 重複直到模型給出最終答案。關鍵：真正執行的是你的程式，不是模型。

常見坑

工具描述寫不清楚，模型就會亂用；工具清單太長會佔上下文（第 1 週學過）；執行前要檢查參數與權限，尤其是寫入或刪除。

安全

因為執行權在你的程式，你可以在執行前加確認或白名單。實體裝置（如今天新聞的儀器）更要有人工確認與停止機制，這是一般原則。

動手做（勾選記錄進度）

貼給 Claude Code 的指令

請先閱讀 Claude 官方文件中關於 tool use 的說明，然後用繁體中文：1) 說明工具定義需要哪些欄位；2) 畫出一次完整的呼叫迴圈；3) 幫我設計一個只讀的『列出最近修改的筆記』工具定義。不確定的地方請明說，不要編造 API 欄位。
